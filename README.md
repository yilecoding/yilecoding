## 项目

### 集团统一业务平台

`Java 17` `Spring Boot 3` `KingbaseES` `Vue 3` `Liquibase`

上市制造企业的集团级中后台，Maven 多模块 + Vue3 单体前端。

- 审批流引擎：平台内置顺序流运行时，对外只暴露业务门面与 SPI，业务模块不接触引擎内部；已接入会议室预约等场景。
- 待办分发走**事务性 Outbox**：事件与业务变更同事务落库，由租约式 relay 投递到 OA / WPS 等外部渠道，替掉事务内直接远程调用。
- 平台自身作为 **OAuth2 / OIDC 身份提供方**：授权码、令牌自省与吊销、RP-initiated logout、重定向 URI 校验，客户端以数据形式管理。
- 个人网盘、文件预览（纯前端渲染文档 / PDF / OFD / DWG）、扫码登录、项目协同等模块的后端与前端实现。

### Ragent AI — 企业级 RAG 智能体平台

`Spring Boot` `React` `RAG` `向量检索` `大模型集成`

针对垂直领域大模型落地的长文本推理与幻觉问题做的预研与二次开发。

- 独立跑通「采集 → 清洗 → 分块 → 向量化 → 入库 → 检索」全链路，实践基于文档结构的分块策略与稠密 + 稀疏多路检索。
- 代码级剖析大模型驱动的 Agent 路由与意图树识别，以及 MCP 协议下的工具动态调用与长程会话记忆。
- 设计会话记忆管理：保留近 N 轮对话并自动摘要压缩，在控制 Token 成本的同时保持上下文连续。

### 电力市场仿真系统

`Python` `Django` `DRF` `Vue 3` `TypeScript` `GoJS 3` `AG-Grid Enterprise`

电力行业的市场仿真与分析平台，支撑潮流计算、静态安全分析与市场规则配置。

- **后端**：Django + DRF 对接潮流计算与静态安全分析引擎，负责多维仿真结果与市场申报数据的清洗、重采样与序列化，配合 RBAC 交付业务 API。
- **大模型辅助单线图排版**：传统图论算法在变电站单线图上布局失真，改为引入大模型辅助空间计算，结合母线水平、11 种电力设备相对位置等物理约束输出节点路由策略，大幅减少人工调参。
- **大规模拓扑渲染**：GoJS 3 构建支持 11 种设备元件的图表编辑器，针对 500–600 节点主接线图的渲染阻塞采用增量更新与视口裁剪，并定制智能连线算法，渲染性能提升约 70%，交互稳定在 60fps。
- **海量数据看板**：基于 AG-Grid Enterprise 封装多实例缓存，用 GridApi 状态托管解决多表切换的内存激增，支撑大规模交易数据的即时比对与透视。

### 智能作文测评平台

`Spring Boot` `Redis` `Vue 3` `微信支付 V3` `Docker`

面向中小学的作文测评 SaaS，10000+ 教师、90000+ 学生、100 万+ 作文数据。

- Redis 多级缓存降低高频访问下的数据库 I/O 压力，保证百万级数据量下的响应稳定性。
- 用 `CompletableFuture` 并行提取作文详情页的多源数据；联考万人级统计报表通过 SQL 执行计划调优 + 中间表预计算，解决深度分页与大表关联的查询瓶颈。
- 接入微信支付 V3，配套带补偿机制的异步勋章体系，保证高并发下业务流程最终一致。
- 阿里云云效搭建 CI/CD 流水线，Docker 容器化部署 + 健康检查。
